📖 How to setup Google Apps Script & JSON Format

1. Google Apps Script Setup

  1. Create a blank text file in your Google Drive. Right-click it, select Share, and set general access to Anyone with the link.
  2. Copy the File ID from the sharing link (the long string of characters between /d/ and /view).
  3. Go to script.google.com and click New Project.
  4. Open this Sample Google Script, copy its contents, and paste it into your new Apps Script project.
  5. Inside the script editor, locate the variable for the File ID and replace it with the one you copied in Step 2.
  6. Click Deploy > New deployment in the top right.
  7. Select the gear icon and choose Web app.
  8. Set Execute as to Me and Who has access to Anyone.
  9. Click Deploy, copy the resulting Web app URL, and paste it in the input above.

2. JSON Question Format Example

Your quiz data must be a JSON array of objects. Use 0-based indexing for correctAnswers (e.g., 0 is the first option). The app supports multiple correct answers.

[
  {
    "question": "What is the capital of France?",
    "options": ["Berlin", "London", "Paris", "Rome"],
    "correctAnswers": [2]
  },
  {
    "question": "Which of these are primary colors?",
    "options": ["Red", "Green", "Blue", "Yellow"],
    "correctAnswers": [0, 2]
  }
]
